# بيانات المحتوى

لا توجد هنا نسخة محلية للنص القرآني في هذا الإصدار الأولي. شاشة المصحف تجلب قائمة السور والآيات من Quran.com API عند توفر الإنترنت.

قبل النشر:
1. راجع شروط استخدام Quran.com API وسياسة الاستخدام المناسبة للتطبيق.
2. نزّل بيانات قرآنية موثوقة ومصرّحًا باستخدامها، وتحقق من الرسم العثماني وعلامات الوقف والتشكيل.
3. أضف اختبارات تحقق من عدد السور (114) وربط كل آية بالسورة ورقمها.
4. لا تستخدم بيانات تجريبية أو نصوصًا مولدة آليًا بدل النص القرآني.
5. لا تضع هذه البيانات في التطبيق إلا بعد التحقق من الترخيص والمصدر.
