# القرآن الكريم — Flutter starter

نسخة تأسيسية فعلية لمشروع Flutter بواجهة عربية RTL. تتضمن:
- واجهة رئيسية وهوية خضراء/ذهبية.
- شريط تنقل سفلي.
- جلب قائمة السور من Quran.com API.
- فتح السورة وجلب النص العثماني من API عند الاتصال.
- بحث بسيط في أسماء السور وأرقامها.
- وضع ليلي.
- أذكار أولية مع تنبيه واضح إلى ضرورة توثيق المحتوى.
- مسبحة إلكترونية تحفظ العدد والهدف والذكر محليًا باستخدام SharedPreferences.
- اختبار واجهة أساسي.

## المتطلبات

- Flutter SDK حديث (Dart 3.3+)
- Android Studio أو Xcode حسب المنصة
- اتصال إنترنت لعرض بيانات السور والآيات في هذا الإصدار

## التشغيل

```bash
flutter pub get
flutter run
```

## الاختبار والتحليل

```bash
flutter analyze
flutter test
```

## بناء APK

```bash
flutter build apk --release
```

المسار المتوقع بعد نجاح البناء:
`build/app/outputs/flutter-apk/app-release.apk`

## الحالة الحالية والقيود

هذه **نسخة تأسيسية قابلة للتشغيل والتطوير وليست التطبيق النهائي المتكامل**. بيئة الإنشاء التي أُعدت فيها الملفات لا تحتوي على Flutter SDK، لذلك لم يُبنَ APK ولم تُنفّذ اختبارات Flutter هنا.

غير منفذ بعد:
- تخزين بيانات المصحف محليًا والعمل الكامل دون إنترنت.
- قاعدة بيانات محلية للسور والآيات مع تدقيق مستقل.
- تفسير وترجمات مع توثيق التراخيص والمصادر.
- تشغيل التلاوة الصوتية في الخلفية وتنزيل الملفات.
- خطة الحفظ والمراجعة والمفضلة وسجل القراءة.
- مواقيت الصلاة والقبلة والتنبيهات.
- مزامنة اختيارية، وإمكانية الوصول المتقدمة، واختبارات أجهزة فعلية.

## دقة المحتوى

- الآيات تُجلب من Quran.com API وليست مولدة بواسطة الذكاء الاصطناعي.
- الآية في بطاقة «ورد اليوم» ثابتة في هذه النسخة، وليست اختيارًا يوميًا متغيرًا.
- الأذكار المعروضة أولية، ويلزم مراجعة مصدر كل ذكر وعدده قبل النشر.
- يجب التحقق من شروط API والتراخيص ومراجعة النصوص قبل اعتماد إصدار إنتاجي.
