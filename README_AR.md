# حزمة تنفيذ خطة تطبيق القرآن الكريم

المستودع المستهدف: `iAl-Baron/al-quran-flutter`

## محتويات الحزمة

- `lib/quran_service.dart`: جلب قائمة السور والآيات من AlQuran Cloud، حفظ نص كل سورة بعد فتحها، حفظ آخر موضع قراءة والمفضلة، وتنزيل ملف صوت الآية إلى مساحة التطبيق.
- `lib/quran_reader_page.dart`: واجهة قراءة المصحف، اختيار السورة، البحث في نص السورة، حجم الخط، المفضلة، تلاوة عبد الباسط عبد الصمد مرتل، تشغيل الصوت المحفوظ، وتنزيل صوت الآية.
- `lib/texts_page.dart`: نسخة محدثة من صفحة الأدعية/الزيارات مع فتح المصحف من الشريط العلوي والقائمة وحفظ المفضلة محليًا.
- `lib/prayer_qibla_page.dart`: اختيار يدوي لمدينة عراقية، مواقيت الصلاة من AlAdhan API مع اختيار طريقة الحساب، حساب اتجاه القبلة رياضيًا، واستخدام حساس البوصلة إن توفر.
- `lib/tasbih_page.dart`: سبحة بأذكار متعددة تحفظ الذكر والعدد محليًا.
- `pubspec.yaml`: الاعتماديات المطلوبة. أزيل مرجع ملف خط غير موجود في المستودع حتى لا يتعطل بناء الأصول، ويستخدم التطبيق خط النظام العربي.
- `.github/workflows/build.yml`: تحليل واختبارات ثم بناء APK ورفع artifact بعد التأكد من وجود الملف؛ ينشئ مجلد Android في CI إذا لم يكن موجودًا في المستودع.
- `test/tasbih_page_test.dart`: اختبار واجهة أولي.

## طريقة الدمج

1. أنشئ فرعًا ونسخة احتياطية من المشروع.
2. انسخ الملفات من الحزمة إلى المسارات نفسها في مشروعك، مع استبدال الملفات التي لها أسماء متطابقة.
3. شغّل:
   ```bash
   flutter pub get
   flutter analyze
   flutter test
   flutter build apk --release
   ```
4. اختبر على جهاز أندرويد حقيقي، خصوصًا الصوت والبوصلة وقراءة القرآن دون اتصال.
5. ارفع التغييرات إلى فرع منفصل وافتح Pull Request بدل استبدال `main` مباشرة.

## نطاق التنفيذ والقيود الحالية

- تم ربط مدخل المصحف بصفحة الأدعية والزيارات دون إزالة عناصر التنقل الأصلية.
- نص السورة يُخزّن محليًا عند جلبها؛ هذا لا يعني أن جميع السور محفوظة مسبقًا. يجب فتح السورة مرة مع الإنترنت حتى تتوفر محليًا.
- تنزيل الصوت يعمل لكل آية على حدة. لم يُنفّذ تنزيل شامل لكل التلاوات مع قائمة انتظار واستكمال تنزيل بعد الانقطاع أو إدارة مساحة متقدمة.
- المواقيت تعتمد على API خارجي وطريقة حساب محددة، وقد تختلف عن تقويم الجهة الدينية المحلية. اختبر الطريقة والتوقيت للمدينة المقصودة قبل الاعتماد.
- اتجاه القبلة يعتمد على المدينة المختارة يدويًا؛ البوصلة تعتمد على حساس الجهاز وقد لا يكون موجودًا أو يحتاج إلى معايرة.
- لم تُنفّذ تنبيهات الصلاة الفعلية، ولم يُستكمل تحويل كل الأذكار والزيارات إلى نصوص كاملة موثقة المصدر. صفحة الأذكار الأصلية تحتوي قائمة عناوين وليست مكتبة نصوص كاملة.
- لم تُنفّذ مشاركة صورة آية ولا تنزيلات صوت مجمعة ولا اختبارات شاملة لصحة نص القرآن.
- راجع ترخيص النصوص والخطوط والتلاوات وشروط مزودي البيانات قبل النشر.
- هذه الحزمة لم تُحلّل أو تُبنَ باستخدام Flutter في هذه البيئة. لا يوجد ادعاء بأن البناء نجح أو أن APK جاهز.
- لم يتم رفع الملفات إلى GitHub لأن تكامل الكتابة رفض إنشاء الفرع بخطأ `403 Resource not accessible by integration`.

## نقاط يجب إكمالها قبل اعتبار الخطة مكتملة

- إضافة بيانات قرآنية موثقة قابلة للتحقق أو توقيع checksums للمصدر.
- تنزيل كامل نص المصحف والصوت مع نسبة تقدم، استكمال، وإدارة مساحة.
- حفظ المفضلة ونصوص الأذكار والزيارات في تخزين محلي موحد.
- تنفيذ إشعارات الصلاة مع طلب الصلاحيات وتحديد سياسة الإشعار.
- إضافة اختبارات للقراءة والبحث والتخزين والصوت والحسابات.
- اختبار قارئات الشاشة، تباين الألوان، أحجام الشاشة، والوضع الليلي.
- مراجعة روابط التلاوة والتراخيص فعليًا قبل الإصدار.
